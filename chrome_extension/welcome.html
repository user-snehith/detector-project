🎉 Welcome to Phishing URL Detector!

Your browser is now protected against phishing links. Here's how to get started:

Step 1: Start the Detector

Make sure our phishing detection server is running. Open a terminal and run:

cd phishing_detector_v2
streamlit run frontend/app.py

This starts the detector on http://localhost:8501

Step 2: Test the Extension

Visit any website and click on links. The extension will automatically check suspicious URLs before allowing navigation.

Test with Example.com

⚠️ Important Note

The extension works best when the detector server is running. If you see connection errors, make sure the server is started on port 8501.
